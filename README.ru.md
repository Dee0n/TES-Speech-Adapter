# TES Speech Adapter

**Русское распознавание речи со знанием лора для AI-модов Skyrim (CHIM / DwemerDistro).**

[Read in English →](README.md)

Обычный speech-to-text не знает Тамриэль. Скажешь *«Алвор»* — распознаватель слышит
*«Алла»*; скажешь *«Аванчнзел»* — получишь *«аванчный зел»*. Этот проект
превращает сервис LocalWhisper из DwemerDistro в распознаватель, который знает
каждого NPC, город, данжен, заклинание и артефакт именно вашего прохождения —
на русском языке.

**Название осталось историческим.** `server/remote_faster_whisper.py` умеет
работать с двумя движками: настоящим faster-whisper и `engine: gigaam`
(GigaAM v3 от Сбера, по HTTP, порт 8026) — для русского языка этот репозиторий
ставит именно конфиг с GigaAM (`config-Large-GPU-RU*.yaml`). В обоих случаях
распознаватель сидит за тем же слотом «Local Whisper» в CHIM, и всё
перечисленное ниже (hotwords, лексикон, fuzzy-коррекция) работает поверх
любого из движков.

## Что внутри

| Слой | Что делает |
|---|---|
| **Русская модель** | Движок Whisper: вместо английской базовой модели — [`bzikst/faster-whisper-large-v3-russian`](https://huggingface.co/bzikst/faster-whisper-large-v3-russian-int8), large-v3, дообученная на русской речи. Движок GigaAM: собственная русская модель Сбера, отдельным сервисом (шаг `[8/10]` в `install.sh`) |
| **Контекстные hotwords** | CHIM-сервер при каждом запросе передаёт декодеру имена NPC, *которые прямо сейчас рядом с вами* (из журнала игровых событий), плюс недавно встреченных NPC (Whisper: настоящие hotwords; GigaAM: сверка имён после распознавания) — собеседник всегда в словаре |
| **Полный игровой лексикон** | Экстрактор в комплекте парсит `*_russian.strings` прямо из BSA-архивов игры (xEdit не нужен) — словарь из **14 000+ имён собственных**: NPC, локации, предметы, заклинания, книги, квесты |
| **Fuzzy-посткоррекция** | Матчинг по Левенштейну на RapidFuzz «примагничивает» промахи к настоящим именам (*«Финдал» → «Фендал»*), понимает русские падежи — *«Лидию»* **не** превратит в *«Лидия»*, и склеивает имена, разбитые распознавателем надвое (*«аванчный зел» → «Аванчнзел»*) |
| **Фикс пунктуации XTTS** | XTTS v2 на русском иногда озвучивает висящую точку как иностранное слово («ponte») — патч TTS-коннектора вычищает такую пунктуацию перед синтезом |
| **Вотчдог** | Перезапускает сервис распознавания (Whisper или GigaAM — какой выбран в `engine:`), если тот тихо умер |

Результат на реальном аудио (синтезировано игровыми голосами XTTS и прогнано
через полный игровой конвейер):

> Скажи **Балгруфу**, что мы нашли откос **Крегвеллоу** возле **Ривервуда**. **Фендал** и **Оргнар** уже там.
> Мы спускались в **Аванчнзел**, а потом навестили **Авентуса Аретино** в **Виндхельме**.

Задержка на прогретой модели: **~0.4 с** на фразу 3.5 с (RTX 5070 Ti,
int8-модель), включая всю постобработку.

## Требования

- [CHIM](https://www.nexusmods.com/skyrimspecialedition/mods/126330) с установленным DwemerDistro (WSL2), компоненты **LocalWhisper** и **CUDA**
- NVIDIA GPU с ~2 ГБ свободной VRAM для int8-модели (конфиг float16 тоже в комплекте)
- Русская локализация Skyrim (для извлечения лексикона из BSA)

Владельцам RTX 50xx (Blackwell): в дистро лежит ctranslate2 4.4, который на
sm_120 **зависает намертво**. Установщик обновляет его до ≥4.6 и доставляет
недостающий cuBLAS для CUDA 12 — уже одно это чинит LocalWhisper на 50-й серии.

## Установка

```
wsl -d DwemerAI4Skyrim3 -- bash /mnt/<диск>/путь/к/TES-Speech-Adapter/install.sh "/mnt/<диск>/путь/к/Skyrim/Data"
```

Второй аргумент (папка `Data` вашего Skyrim, как она видна из WSL) необязателен —
он строит полный лексикон на 14 тысяч имён из BSA-архивов вашего лоад-ордера.

Затем в веб-панели CHIM: **Configuration → STT → Local Whisper**
(URL `http://127.0.0.1:9876/api/v0/transcribe`).

**Перезапускайте `install.sh` после каждого обновления CHIM** — апдейтер
откатывает пропатченные файлы через git reset. Конфиги, лексиконы и вотчдог
обновления переживают без потерь.

### Проверка

```bash
wsl -d DwemerAI4Skyrim3 -- curl -s -X POST \
  -F "audio_file=@/путь/к/любому.wav" http://127.0.0.1:9876/api/v0/transcribe
```

## Расширение словаря

- `HerikaServer/stt/tes_lexicon_ru.txt` — курируемый список лорных терминов,
  по записи на строку (можно через запятую). Добавляйте NPC из модов, кастомные
  локации — что угодно.
- Имена вашего прохождения не требуют обслуживания: они читаются на лету из
  базы CHIM (встреченные NPC, открытые локации, фракции).
- Упрямые слова добиваются точечными regex-правилами в `transformations`
  активного `config-*.yaml`.

## Планы

- Парсер ESP-записей: имена из плагинов модов без `.strings`
