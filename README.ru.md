# FuturePresent

[Read in English →](README.md)

Это моя сборка Skyrim: SE 1.5.97, сильно модифицированный (Requiem, профиль
RFAD_SE), поверх [CHIM](https://www.nexusmods.com/skyrimspecialedition/mods/126330)
на DwemerDistro — NPC говорят через LLM, а не по ванильным диалоговым
деревьям. В этом репозитории — всё, что я достроил сверху, на русском, чтобы
говорить с игрой вслух и чтобы рассказчик реально мог менять мир, а не
только рассказывать о нём.

Начиналось всё с «починить распознавание речи», а выросло в две отдельные
вещи в одном репозитории. Обе имеют смысл только вместе с установленным
CHIM — это не универсальный инструмент для всех.

## Часть 1: правильно слышать русскую речь

Обычный speech-to-text не знает Тамриэль. Скажешь *«Алвор»* — услышит
*«Алла»*; скажешь *«Аванчнзел»* — получишь *«аванчный зел»*. Эта часть ставит
русскую модель, подкидывает ей имена тех, кто реально сейчас рядом с тобой
(прямо из журнала событий CHIM), и подчищает результат после — падежи,
разорванные надвое имена, близкие промахи против словаря на 14 тысяч имён,
собранного прямо из BSA-архивов твоего load order.

Сервис по-прежнему называется `remote_faster_whisper.py` и сидит в слоте
CHIM «Local Whisper», но Whisper запускать не обязан: ставишь в конфиге
`engine: gigaam` — и он проксирует запросы в GigaAM v3 от Сбера (именно так
настроен русский конфиг, который ставит этот репозиторий). Hotwords,
словарь и подчистка результата работают одинаково, какой бы движок ни
распознавал звук.

Ещё есть мелкий фикс XTTS: он иногда озвучивает висящую точку в конце фразы
как иностранное слово.

Пример на реальном синтезированном аудио, прогнанном через весь конвейер:

> Скажи **Балгруфу**, что мы нашли откос **Крегвеллоу** возле **Ривервуда**. **Фендал** и **Оргнар** уже там.
> Мы спускались в **Аванчнзел**, а потом навестили **Авентуса Аретино** в **Виндхельме**.

## Часть 2: рассказчик, который реально что-то делает

Обычно рассказчик CHIM только говорит. Плагины в `ext/` (CHIM их сам
подгружает, ядро я не трогаю) дают ему возможность выполнять настоящие
консольные команды через SKSE-плагин — и, что важнее, знать, сработали ли
они, а не уверенно описывать результат, который никто не проверял.

Из этого получилось примерно следующее:

- Журнал того, что рассказчик реально сделал в прошлый раз, с настоящим
  успехом или провалом — показывается ему перед следующей репликой. Больше
  никакого «он снова жив», когда воскрешение тихо провалилось.
- Проверка перед тем, как команда уйдёт в консоль: список разрешённого
  вместо списка запрещённого, поиск ID по индексу, собранному из твоего
  собственного load order (161 тысяча записей — NPC, предметы, ячейки,
  заклинания, квесты — а не придуманные FormID), ограничение на массовый
  спавн, отсев повторов.
- Команды под то, что реально нужно во время игры: нормально исцелить,
  поженить двух NPC (и чтобы оба это реально помнили), дать персонажу
  постоянное воспоминание, поменять, чем он занимается весь день, по-
  настоящему отдать дом или лошадь, пустить слух по холду, переписать
  характер персонажу так, чтобы отношения к нему подстроились сами.
- Автосейв перед тем, что трудно будет откатить.

Всё это не проектировалось заранее — это журнал того, что чинилось от сессии
к сессии, в `docs/applied-log.md`, включая то, что я сделал неправильно с
первого раза, и тупики (пара задумок для бога уперлась в то, что исходников
Papyrus для некоторых модов просто не существует; это тоже честно записано,
а не спрятано).

## Установка

```
wsl -d DwemerAI4Skyrim3 -- bash /mnt/<диск>/путь/до/этого/репозитория/install.sh "/mnt/<диск>/путь/до/Skyrim/Data"
```

Путь к `Data` Skyrim не обязателен — он нужен, чтобы собрать полный словарь
из твоего реального load order. Перезапускай `install.sh` после каждого
обновления CHIM — обновления откатывают патченные файлы ядра, а установщик
накатывает их заново и копирует плагины из `ext/`.

После установки, в веб-панели CHIM: **Configuration → STT → Local Whisper**,
URL `http://127.0.0.1:9876/api/v0/transcribe`.

```bash
# быстрая проверка, что голосовая часть жива
wsl -d DwemerAI4Skyrim3 -- curl -s -X POST \
  -F "audio_file=@/path/to/any.wav" http://127.0.0.1:9876/api/v0/transcribe
```

`php tools/test_ext.php --write` гоняет настоящую регрессионную проверку
плагинов бога на одноразовом тестовом NPC — стоит запускать после любого
изменения здесь или после обновления CHIM, прежде чем доверять этому в
реальном прохождении.

## Расширение словаря

- `HerikaServer/stt/tes_lexicon_ru.txt` — по одному термину на строку, для
  всего, что не подхватилось автоматически.
- Имена NPC, которых ты реально встретил, и открытых локаций обслуживать не
  нужно — они идут напрямую из базы CHIM.
- Упрямые ошибки распознавания можно точечно поправить через
  `transformations` в активном `config-*.yaml`.

## Что не сделано

- Контент модов, которые не поставляют `.strings` (только ESP), в словарь
  ещё не попадает.
- Настоящая морфология (pymorphy3) вместо нынешней эвристики по окончаниям.
- Консоль бога по-прежнему не может сдвинуть стадию квеста без
  подтверждения игрока — пока намеренно.
- Пока нет настоящего решения, чтобы рассказчик узнавал результат команды в
  той же реплике, а не в следующей — для этого пришлось бы блокировать
  запрос до ответа игры, а это небезопасно делать просто так.
