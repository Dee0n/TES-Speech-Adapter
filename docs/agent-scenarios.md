# Свободные сценарии для агента (приёмочный список)

2026-10-03. Не рецепты: это проверочные цели. Агенту их не показывают — по ним смотрим, каких
**примитивов** не хватает. Статус: ✅ покрыто инструментами (сухой прогон или разбор),
🟡 частично / через сырую консоль, ❌ нет примитива. В игре не проверено ничего.

## 1. Игрок: кем стать

| Цель | Статус | Чего не хватает |
|---|---|---|
| «бог воровства / алхимии / кузнец / лучник» | ✅ (сухие прогоны) | — |
| «архимаг разрушения», «некромант» | 🟡 | поиск заклинаний по школе и рангу (в индексе есть эффекты, нет школы/уровня) |
| «дай все крики» | ❌ | слова силы и крики не индексируются (WOOP/SHOU), нет инструмента teach_shout |
| «зачаруй мой меч на огонь» | ❌ | наложение зачарования на предмет — нужен мост (SKSE CreateEnchantment) |
| «сделай меня вампиром / оборотнем / вылечи» | ❌ | это функции скриптов игры (PlayerVampireQuest, CompanionsHousekeeping), нужен мост |
| «смени расу / рост / вес» | 🟡 | setscale есть; setrace не разрешён стражем |
| «сделай меня богатым» | ✅ | — |
| «верни как было» (отмена) | ❌ | журнал «было → стало» по задаче и обратные действия |

## 7. Надёжность самого агента

- подтверждение перед необратимым (убийство важных NPC, стадии квестов) — ❌;
- очередь целей (сейчас одна задача, вторая отклоняется) — 🟡;
- отчёт о ходе голосом на длинной задаче — ❌ (сейчас только начало и итог);
- остановка при загрузке сейва (игровое время пошло назад) — ❌;
- голосовое «стоп» / «отмени» — ❌.

## Приоритет (что даёт больше всего сценариев за одну доработку)

1. **Инструменты из того, что страж уже умеет**: marry, relation между NPC, heal, resurrect/kill,
   routine, hypnosis, teleport к NPC, NPC в место. Только worker.php.
2. **Запросы без действий**: где NPC, отношения по городу, журнал квестов. Только БД CHIM.
3. **Группы**: найти актёров по фракции / локации / «рядом» (индекс + мост).
4. **Стадии квестов под подтверждение**: читать стадию, ставить с автосейвом и согласием игрока.
   Открывает «тан», «заверши квест», «начни квест».
5. **Преступления и торговцы**: штраф, розыск, золото торговца.
6. **Индекс**: школа и ранг заклинаний, крики, связь ячейка → локация («весь город мой»).
7. **Мост**: зачарование предмета, вампир / оборотень, обстановка дома.
8. **Роли NPC**: жрец лечит, маг учит заклинанию, кузнец берёт заказ.
9. **Отмена и подтверждения.**
